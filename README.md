# 🛒 Amazon E-commerce Clone

A modern Amazon-inspired e-commerce web application built using **HTML**, **CSS**, and **JavaScript (ES6 Modules)**.

This project was developed as part of my JavaScript learning journey while following the SuperSimpleDev course. I extended the project by implementing additional features, improving the code structure, fixing deployment issues, and enhancing the shopping experience.

# ✨ Features

## 🏠 Home Page

- Dynamic product rendering
- Product images
- Product ratings
- Product prices
- Quantity selector
- Add to Cart button
- "Added to Cart" animation
- Search functionality
- Responsive layout

---

## 🛒 Shopping Cart

- Add products
- Increase quantities
- Remove products
- Real-time cart quantity update
- Cart data stored in Local Storage
- Dynamic cart rendering

---

## 💳 Checkout

- Order summary
- Payment summary
- Delivery options
- Shipping cost calculation
- Estimated delivery dates
- Tax calculation
- Total price calculation

---

## 📦 Orders

- Order history
- Product details
- Order total
- Order date
- Buy Again functionality
- Track Package button

## 🚚 Package Tracking

- Estimated delivery date
- Delivery progress bar
- Current delivery status
    - Preparing
    - Shipped
    - Delivered
- Progress calculated using order dates

## 🔍 Search

- Search products by name
- URL query parameter support
- Dynamic product filtering
